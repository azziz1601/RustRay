RustRay

Native Rust Android VPN for VLESS, VMess, Trojan, and SSH hybrid tunnels. Open source, lightweight, and built with xray-rust-mobile plus a custom russh 0.65 + BadVPN UDPGW engine.

GitHub repository Download APK Full documentation

Features

  • VLESS, VMess, Trojan with TLS, REALITY, WebSocket, gRPC, XHTTP, and more.
  • Native Rust SSH Hybrid engine: 7 injector modes, 1–4 parallel connections, enhanced tuning.
  • Encrypted .rr profile export/import with AES-256-GCM and locked fields.
  • BadVPN UDPGW client, fake IP, sniffing, custom DNS, per-app split tunneling.
  • Home-screen widget, Quick Settings tiles, live traffic notification, EN/ID UI.

Download

Install the ABI that matches your device:

  • app-arm64-v8a-release.apk — most modern 64-bit ARM Android phones.
  • app-armeabi-v7a-release.apk — older 32-bit ARM devices.
